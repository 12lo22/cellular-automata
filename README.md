# Cellular Automata

Python implementation of one-dimensional cellular automata Rule 30 and Rule 110.

## Rule 30

The following animation shows the evolution of Rule 30 over 30 generations.

![Rule 30 animation](rule30.gif)

## Files

- `rule30.py`: Prints the evolution of Rule 30 in the terminal.
- `rule30_gif.py`: Generates an animated GIF of Rule 30.
- `rule30.gif`: Animation output generated by the script.

## Requirements

- Python 3
- NumPy
- Matplotlib
- Pillow

## Run

```bash
python rule30.py
python rule30_gif.py
```
